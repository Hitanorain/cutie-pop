# 萌萌消消乐 · Cutie Pop

单文件网页三消游戏，手机、平板、电脑都能玩：用鼠标或手指拖动小萌物和旁边的交换，三个一样的连成一排就消掉。

- 两个世界，各 30 关、各有自己的萌物、配色和曲子：
  - 🐰 萌宠乐园：草莓兔、小黄鸡、小蓝鲸、青蛙仔、紫猫咪、橘子熊
  - 🍓 水果乐园：草莓、橙子、柠檬、西瓜、葡萄、桃子（木琴曲子，十字形、T 形棋盘）
- 小萌物会眨眼、会看着你的手指、跟着节拍跳舞
- 4 个连一排变火箭，L/T 形变泡泡炸弹，5 个连一排变彩虹星；特殊萌物互相交换有组合大招
- **萌力**：短时间里消得越多萌力越高，背景音乐一层层加乐器、加速，满了进入「萌力爆发」——升调、分数翻倍，还有越来越激动的鼓励语音（中文 / English 两套，右上角「中 / EN」切换）
- 卡住了可以用道具（每局次数有限，不算步数）：🔨 小锤子 ×3、🔀 洗牌 ×2、🪄 魔法棒 ×1（变出彩虹星）、⏳ +3 步 / +10 秒 ×1
- 闯关模式每个世界 30 关（分数目标 + 收集目标，爱心、杯子、金字塔等造型棋盘），以及 60 秒挑战（每个世界单独记录最高分）

直接用浏览器打开 `index.html` 就能玩；进度保存在浏览器本地。
